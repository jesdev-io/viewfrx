The custom viewfrx logo sources are the Draw.io SVGs in the repository's `assets/` directory. `viewfrx-logo.png` is rasterized from `viewfrx_logo.drawio_15pt.svg` for in-app branding; `viewfrx-icon.png` is rasterized from `viewfrx_logo.drawio_15pt_icon.svg` for the application and installer icon. Keep the SVG sources as the editable originals.
